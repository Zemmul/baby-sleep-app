# Audio Directory

This directory contains audio files for the Baby Sleep & Rhyme Time app.

## Required Audio Files

1. `white-noise.mp3` - A soothing white noise sound for babies to sleep to.
2. `gentle-rain.mp3` - Gentle rainfall sounds for a calming environment.
3. `coffee-shop.mp3` - Ambient coffee shop background noise.
4. `ocean-waves.mp3` - Calming ocean waves sound.

## Audio Specifications

- Format: MP3
- Quality: High (320kbps recommended)
- Duration: At least 5 minutes, ideally 10+ minutes
- Loop: All audio files should loop seamlessly without noticeable transitions

## Sourcing Audio

You can source these audio files from:
1. Royalty-free sound libraries
2. Create your own recordings
3. Purchase licensed audio

Make sure you have the proper rights to use these audio files in your app.
