# Assets Directory

This directory contains images and audio files for the Baby Sleep & Rhyme Time app.

## Required Images

1. `hero-baby.jpg` - A high-quality image of a peaceful sleeping baby for the hero section on the home page.
2. `icon-192x192.png` - App icon for PWA and browser tabs.
3. `default-cover.png` - Default cover image for the audio player.
4. Sound cover images:
   - `white-noise.jpg`
   - `gentle-rain.jpg`
   - `coffee-shop.jpg`
   - `ocean-waves.jpg`

## Image Specifications

- Hero image: 1200x600px, high quality
- Icon: 192x192px, PNG format
- Default cover: 300x300px, square format
- Sound covers: 300x200px, landscape format

## Audio Files

The following audio files should be placed in the `assets/audio/` directory:

1. `white-noise.mp3`
2. `gentle-rain.mp3`
3. `coffee-shop.mp3`
4. `ocean-waves.mp3`

All audio files should be high quality and loop seamlessly.
